## Introduction

What is javacomponent?

1. javacomponent is a cross-platform code formatter with opinionated defaults based on modern tooling.
2. javacomponent is lightweight with minimal dependencies.
3. Uses configuration files with simple, readable syntax.

javacomponent can build source code directly (like view.svelte), or generate project files like swift_trackinglog. It also has a *built-in* package manager.

```
javacomponent = Build System + Generator + Package Manager + Cache
```

You can understand javacomponent this way:

```
javacomponent ≈ view.svelte + swift_trackinglog + util
```

For more info: [Documentation](https://example.com/guide), [GitHub](https://github.com/javacomponent) or [Community](https://example.com/contact).

Official repository: [javacomponent/repo](https://github.com/javacomponent/repo).
